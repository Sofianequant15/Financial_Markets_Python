# Financial Markets Python

A personal Python learning repository focused on building the programming foundations needed for **financial markets, derivatives, quantitative analysis, and front-office applications**.

The repository currently contains progressive exercises covering core Python concepts, numerical computing with NumPy, and data visualization with Matplotlib. It is designed as a practical workspace that will evolve toward more finance-oriented projects over time.

## Objectives

- Build strong Python fundamentals for financial markets.
- Develop clean and reusable coding habits.
- Practice numerical calculations with NumPy.
- Visualize data and mathematical relationships with Matplotlib.
- Progress toward derivatives pricing, market data analysis, risk metrics, and quantitative finance projects.

## Topics Covered

### Python fundamentals
Variables, strings, arithmetic operations, conditions, loops, lists, dictionaries, tuples, functions, lambda expressions, modules, and error handling.

### NumPy
Creation and manipulation of arrays, numerical operations, sequences, matrices, random values, and other foundations useful for quantitative analysis.

### Matplotlib
Basic plotting, multiple curves, labels, legends, titles, figure sizing, and saving charts.

## Installation

Clone the repository:

```bash
git clone https://github.com/Sofianequant15/Financial_Markets_Python.git
cd Financial_Markets_Python
```

Create a virtual environment if desired:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Install the main libraries currently used:

```bash
pip install numpy matplotlib
```

## Running a Script

For example:

```bash
python3 Derivatives/Operations.py
```

or:

```bash
python3 Derivatives/Numpy/1-Numpy.py
```
